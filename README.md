# Süni İntellekt və Rəqəmsal Həllər Laboratoriyası — LDU

## Layihə haqqında

Bu layihə Lənkəran Dövlət Universitetinin Süni İntellekt və Rəqəmsal Həllər Laboratoriyasını təqdim etmək məqsədilə hazırlanmış veb saytdır.

Saytın əsas məqsədi laboratoriyanın fəaliyyət istiqamətlərini, istifadə olunan texnologiyaları və məqsədlərini tanıtmaqdır.

## Saytın bölmələri

- **Fəaliyyət sahələri** — laboratoriyanın əsas fəaliyyət istiqamətləri
- **Texnologiyalar** — süni intellekt və rəqəmsal həllərlə əlaqəli texnologiyalar
- **Əlaqə** — əlaqə məlumatları üçün bölmə

## İstifadə olunan texnologiyalar

- HTML5
- CSS3
